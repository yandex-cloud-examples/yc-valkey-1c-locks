# Распределенные блокировки для 1С:Предприятия в кластере Yandex Managed Service for Valkey

Кластер [Yandex Managed Service for Valkey](https://yandex.cloud/ru/docs/managed-valkey) можно использовать как хранилище распределенных блокировок для 1С:Предприятия — например, чтобы несколько пользователей не могли одновременно редактировать один и тот же элемент справочника. Интеграция выполняется через промежуточный HTTP-сервер, развернутый на виртуальной машине [Yandex Compute Cloud](https://yandex.cloud/ru/docs/compute). Сервер предоставляет HTTP API для управления блокировками и использует кластер Valkey в качестве бэкенда. Подготовка HTTP-сервера и кластера Managed Service for Valkey описана в [практическом руководстве](https://yandex.cloud/ru/docs/tutorials/infrastructure-management/1c-valkey-locks), необходимый для настройки через Terraform конфигурационный файл [valkey-1c-http.tf](valkey-1c-http.tf) расположен в этом репозитории.
